# vetidem

Vet encode/decode helpers for idem payloads in pipelines.

**Site:** https://theworker02.github.io/vetidem/

## Install / run

```bash
git clone https://github.com/theworker02/vetidem.git
cd vetidem
node src/cli.js
node --test
```
